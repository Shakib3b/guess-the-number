# 🎯 Guess The Number — Python Game

A fun, interactive number-guessing game written in Python.  
Includes difficulty levels, hints, attempt tracking, “warmer/colder” guidance, and replay support.

This project is great for beginners learning:
- variables  
- loops  
- conditions  
- functions  
- randomness  
- basic game logic  

---

## 🚀 Features

### ✔️ Difficulty Levels
Choose from:
- **Easy** (1–20, 10 attempts)
- **Medium** (1–100, 7 attempts)
- **Hard** (1–500, 5 attempts)
- **Custom** (set your own range and attempt limit)

### ✔️ Smart Hints
Use `"hint"` during gameplay (costs 1 attempt):
- Tells you **even/odd**
- Tells you if divisible by 3
- Gives a **narrowed range** based on difficulty

### ✔️ Warm / Cold Feedback
After each guess:
- **Warmer** — you're getting closer  
- **Colder** — you're getting farther  
- Or same distance  

### ✔️ Clean Game Loop
- Tracks attempts  
- Tracks hints used  
- Ends when attempts run out  
- Option to **play again**
